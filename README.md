# Mjfxjas Tap

## How do I install these formulae?

`brew install mjfxjas/tap/<formula>`

Or `brew tap mjfxjas/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "mjfxjas/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
